# CET2007 Week 6 Workshop

.NET 10 console application for the Generics and Collections workshop.

## Exercises included

- Exercise 1: Generic helpdesk message handler using `HelpdeskMsgHandler<T>`.
- Exercise 2: Ticket management using `List<Ticket>` and `Dictionary<string, Ticket>`.
- Exercise 3: Ticket assignment and waiting requests using `Queue<string>`.
- Exercise 4: Undoing the last assignment using `Stack<Ticket>`, resolving tickets, and a console menu.

XML documentation generation is enabled in the project file.

## Run

```bash
dotnet run
```
